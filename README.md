# Bright-coffee-shop-case-study

## Project Overview
This project analyzes sales data for Bright Coffee Shop to identify trends in revenue, customer traffic by time of day, and store performance. The goal is to provide actionable insights to improve operations and increase profitability.

## Files Included
- **20260807_Coffee_shop_case_study.xlsx**: Main dashboard with PivotTables and charts. Shows monthly revenue trends and sales by time bucket.
- **Coffee shop case study.sql**: SQL queries used for data analysis.
- **Coffee shop Presentation.pptx / .pdf**: Final slides with key findings and recommendations.
- **Coffee shop_Planning and Gantt chart.pdf**: Project timeline and tasks.
- **Methodology.pdf**: Data sources, cleaning process, and analysis methods.

## Key Findings
- **Monthly Revenue Growth**: Revenue rose steadily from January (9,329) to June (12,360), showing over 30% growth.
- **Store Performance**: Hell’s Kitchen leads slightly at 21,996, followed closely by Astoria. Midtown trails at 20,401 – performance is consistent across locations.
- **Time of Day**: Mornings are the most profitable, generating nearly 10,000 per store, while revenue. Afternoons are strong, evenings moderate.
- **Product Mix**: Coffee and tea dominate, especially in the morning, accounting for the bulk of sales. Bakery items also perform well, while branded and packaged chocolate underperform.


## Tools Used
- **Excel**: PivotTables, Charts, Dashboard
- **SQL**: Data querying and analysis
- **PowerPoint**: Presentation of insights

## How to Navigate
1. Open the `.xlsx` file to view the interactive dashboard.
